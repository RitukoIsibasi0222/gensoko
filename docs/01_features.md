## FEAT-001: 元素一覧ページ

### 概要
全118元素をカード形式で一覧表示する

### カード表示項目
- 原子番号
- 元素記号（例: `H`）
- 元素名（例: `水素`）
- 分類によるカード背景色の色分け

### カード詳細モーダル（クリック時に表示）
| フィールド | 例 |
|-----------|-----|
| 原子番号 | 1 |
| 元素記号 | H |
| 元素名（日本語） | 水素 |
| 元素名（英語） | Hydrogen |
| 分類 | 非金属 |
| 周期 | 1 |
| 族 | 1 |
| 標準原子量 | 1.008 |

### フィルター・検索
- 番号・記号・名前でのキーワード検索
- 分類でのフィルター（非金属 / アルカリ金属 / 遷移金属 など）
- 周期でのフィルター

### 習得状態バッジ（ログイン時のみ）
各カードに学習状態を表示
- `未学習`（グレー）
- `学習中`（黄）
- `習得`（緑）: ゲームで連続2回正解した元素

## FEAT-002: ゲーム（4択クイズ）

### ゲームモード一覧

| モードID | 問題形式 | 難易度 | 出題範囲 |
|---------|---------|--------|---------|
| `SYMBOL_TO_NAME_LV1` | 記号→名前 | 初級 | 1〜20番 |
| `SYMBOL_TO_NAME_LV2` | 記号→名前 | 上級 | 21〜118番 |
| `NAME_TO_SYMBOL_LV1` | 名前→記号 | 初級 | 1〜20番 |
| `NAME_TO_SYMBOL_LV2` | 名前→記号 | 上級 | 21〜118番 |
| `WEAK_SYMBOL_TO_NAME` | 記号→名前 | 苦手 | 苦手リストのみ |
| `WEAK_NAME_TO_SYMBOL` | 名前→記号 | 苦手 | 苦手リストのみ |

### 1ゲームのフロー

```
ゲーム開始
  ↓
対象元素からランダムに10問を重複なく選出
  ↓
[問題画面] × 10回繰り返し
  ・インジケーター表示（例: ● ● ○ ○ ○ ○ ○ ○ ○ ○）
  ・タイムリミット: 15秒（カウントダウンバー表示）
  ・問題文と4択ボタンを表示
  ・選択または時間切れ → 正誤フィードバック（1.5秒）
  ↓
[結果画面]
  ・正解数 / 10問
  ・正答率
  ・連続最大正解数
  ・かかった時間
  ・間違えた問題の一覧（記号・正解名）
  ・「もう一度」「ホームへ」ボタン
```

### スコアリング
```
基本点:       正解1問につき 100点
時間ボーナス: 残り時間 × 5点
連続正解ボーナス: 3連続 +50点、5連続 +100点、全問正解 +500点
```

### 4択の選択肢生成ルール
- 正解: 出題された元素
- 誤答3つ: **同じ難易度帯**（同じ段階の範囲）からランダム選出
- 正解と誤答が重複しない
- 選択肢の並び順はランダム

### 問題ログの記録（ログイン時のみ）
- 各問の元素ID・正解 or 不正解・回答時間を記録
- 不正解の元素を苦手リストに自動追加

## FEAT-003: 苦手管理

### 苦手リスト画面
- 間違えた元素の一覧をカード表示
- 各カードに「間違えた回数」を表示
- 手動での削除ボタン
- ソート: 間違えた回数順 / 追加日時順

### 苦手リストからの削除条件
- ユーザーが手動で削除
- または 苦手ゲームで2回連続正解した場合に自動削除

### 苦手ゲームの制限
- 苦手リストが5問未満の場合はゲーム開始不可（メッセージ表示）

## FEAT-004: 学習履歴・統計

### マイページで表示する統計
| 項目 | 内容 |
|------|------|
| 総ゲーム数 | 累計プレイ回数 |
| 総正解数 | 累計正解問題数 |
| 平均正答率 | 全ゲームの正答率の平均 |
| 習得済み元素数 | 全118元素のうち習得した数 |
| 連続ログイン日数 | 現在のログインストリーク |
| 正答率グラフ | 直近10ゲームの正答率推移（折れ線グラフ） |

## FEAT-005: アカウント管理

### 登録フロー
```
メールアドレス + ユーザー名 + パスワード入力
  ↓
確認メール送信（有効期限: 24時間）
  ↓
メール内リンクをクリック → メール認証完了
  ↓
ログイン可能（未認証ではゲーム機能を制限）
```

### プロフィール設定
- ユーザー名の変更
- パスワード変更（現在のパスワード確認が必要）
- アカウント削除（確認モーダル → 全データ削除）

## FEAT-007: 管理者機能

### 管理画面（`/admin`）
| 機能 | 内容 |
|------|------|
| ユーザー一覧 | 全ユーザーの一覧・検索 |
| ユーザー詳細 | 学習統計・ゲーム履歴の閲覧 |
| アカウント操作 | 停止・停止解除・強制退会 |
| ロール変更 | 一般 ↔ 管理者の切り替え |
| 統計ダッシュボード | 総ユーザー数・日次アクティブユーザー |

### 管理者アカウント作成ルール
- **UIからの登録は不可**
- CLIコマンド or 環境変数の初期管理者設定のみ

## UI / UX 仕様

### 共通
- レスポンシブデザイン（PC / タブレット / スマートフォン対応）
- ダークモード対応（OS設定に追従 + 手動切り替え）
- キーボード操作: 問題回答時に `1` `2` `3` `4` キーで選択肢を選べる

### ゲーム中断
- ブラウザを閉じた場合、セッションストレージにゲーム状態を保存
- 再訪問時に「前回の続きから再開しますか？」を表示
